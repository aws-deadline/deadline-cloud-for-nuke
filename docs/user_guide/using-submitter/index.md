# Using the Deadline Cloud for Nuke submitter

The Deadline Cloud for Nuke submitter supports two types of jobs.

- [Render Jobs](render-submissions.md) - Render the output files created by one or more of the [Write Nodes](https://learn.foundry.com/nuke/content/comp_environment/rendering/output_write_nodes.html) in your nuke script.
- [CopyCat Training Jobs](copycat-submissions.md) - Perform training for a [CopyCat Node](https://learn.foundry.com/nuke/content/reference_guide/air_nodes/copycat.html) in your nuke script.

## Monitoring your jobs

You can monitor job progress using the Deadline Cloud monitor. For more information, see the [AWS Deadline Cloud guide for using the monitor](https://docs.aws.amazon.com/deadline-cloud/latest/userguide/working-with-deadline-monitor.html).
